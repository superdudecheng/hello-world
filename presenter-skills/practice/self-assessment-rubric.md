# 📋 Self-Assessment Rubric

Use this to review your recorded practice talks — and give it to feedback
partners so their notes are **specific** instead of "that was good." Score each
item 1–5, note **one concrete thing to keep** and **one to change**, then pick a
**single** focus for next time.

> Don't try to fix everything at once. Improve **one dimension per practice
> round.** That's how habits actually change.

**Scale:** 1 = needs major work · 2 = weak · 3 = okay · 4 = strong · 5 = excellent

---

## 1. Content & Structure
| # | Criterion | 1–5 |
|---|---|---|
| 1.1 | There was **one clear core message** I could state in a sentence | |
| 1.2 | The structure was easy to follow (clear beginning, middle, end) | |
| 1.3 | The **opening** hooked attention in the first 30 seconds | |
| 1.4 | The **closing** was deliberate and memorable (not a trail-off) | |
| 1.5 | It was the right length — nothing draggy, nothing rushed | |
| 1.6 | Every part supported the core message (no filler tangents) | |

## 2. Voice & Vocal Delivery
| # | Criterion | 1–5 |
|---|---|---|
| 2.1 | **Pace** was controlled and varied (not rushed) | |
| 2.2 | Used **pauses** effectively (before/after key points) | |
| 2.3 | **Pitch varied** — no monotone; statements landed (no upspeak) | |
| 2.4 | **Volume/projection** was strong and used for emphasis | |
| 2.5 | **Few or no filler words** ("um," "uh," "like," "so") | |
| 2.6 | Clear **articulation** — easy to understand throughout | |

## 3. Body Language & Presence
| # | Criterion | 1–5 |
|---|---|---|
| 3.1 | **Posture** was tall, open, and grounded | |
| 3.2 | **Gestures** were natural and purposeful (returned to home base) | |
| 3.3 | **Eye contact** connected with the audience (no floor/slide staring) | |
| 3.4 | **Movement** was purposeful, not nervous pacing/swaying | |
| 3.5 | **Facial expression** matched the message (warmth where fitting) | |
| 3.6 | No distracting nervous tells (fidgeting, hidden hands, rocking) | |

## 4. Storytelling & Engagement
| # | Criterion | 1–5 |
|---|---|---|
| 4.1 | Included at least one **story or vivid example** | |
| 4.2 | Story had **conflict/stakes** and a clear turning point | |
| 4.3 | Used **"show, don't tell"** / concrete sensory detail | |
| 4.4 | Created **emotion** somewhere (I felt something) | |
| 4.5 | Felt like a **connection/conversation**, not a recital | |

## 5. Overall Impact
| # | Criterion | 1–5 |
|---|---|---|
| 5.1 | Appeared **confident and composed** | |
| 5.2 | Seemed **authentic** — like themselves, not a performance | |
| 5.3 | I was **engaged** the whole time | |
| 5.4 | I'll **remember the core message** tomorrow | |
| 5.5 | Credible and trustworthy (ethos) | |

## For feedback partners

If you're reviewing someone else, the most useful feedback is:
1. **Specific** — "you rushed the ending and dropped your volume," not "it was
   good."
2. **Balanced** — name a genuine strength *and* one clear improvement.
3. **Actionable** — something they can actually change next time.
4. **Kind but honest** — vague praise doesn't help anyone grow.

A good format: **"I liked ___. I'd suggest ___. The one thing I'd change is
___."**
