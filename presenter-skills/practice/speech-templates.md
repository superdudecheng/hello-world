# 📝 Speech Templates & Prep Worksheets

Fill-in-the-blank scaffolds so you never face a blank page. Copy the relevant one
into your notes and fill it in. Remember: these produce **keyword outlines to
speak from**, not scripts to read (see
[Module 1](../curriculum/01-content-and-structure.md)).

---

## 🧭 The universal prep worksheet (start here for any talk)

```
TALK TITLE / OCCASION: ____________________________________

AUDIENCE
  Who are they? _________________________________________
  What do they already know? ____________________________
  What do they care about? ______________________________

CORE MESSAGE (one sentence — if they remember one thing):
  ______________________________________________________

GOAL: After this, I want them to
  ☐ think ______  ☐ feel ______  ☐ do ______

THE HOOK (first 30 seconds — story? question? fact? bold claim?):
  ______________________________________________________

3 KEY POINTS (each with one example/story):
  1. ______________________  → e.g. _____________________
  2. ______________________  → e.g. _____________________
  3. ______________________  → e.g. _____________________

THE CLOSE (restate core message + call to action / callback):
  ______________________________________________________

TIME LIMIT: ______   |   REHEARSED OUT LOUD ___ times
```

---

## 1. The classic informative/keynote talk

```
OPEN:   Hook → "Why this matters to YOU" → preview the core idea
POINT 1: Claim → evidence → story/example
POINT 2: Claim → evidence → story/example
POINT 3: Claim → evidence → story/example
CLOSE:  Restate core message → callback to the hook → final resonant line
```

## 2. The persuasive talk / pitch (Monroe's Motivated Sequence)

```
ATTENTION:     Hook them (story, stat, or provocative question)
NEED:          Show the problem — make them FEEL it affects them
SATISFACTION:  Present your solution clearly
VISUALIZATION: Paint the better future your solution creates
ACTION:        One specific, concrete call to action
```

## 3. The startup / project pitch (short)

```
1. THE HOOK — a memorable one-liner or the problem in human terms
2. THE PROBLEM — who hurts, and how much
3. THE SOLUTION — what you do, in one clear sentence
4. WHY IT WORKS / TRACTION — proof, demo, or evidence
5. THE ASK — exactly what you want from this audience
```

## 4. The personal story / "Moth-style" talk

```
- Open IN the moment (drop them into a scene, mid-action)
- Set the stakes — what did I want? what was at risk?
- The struggle — what went wrong / the obstacle
- The turning point — the moment of change or realization
- The resolution — how it ended
- The point — what it taught me / why I told you this
```

## 5. The team update / demo (work)

```
- Bottom line up front: the ONE thing you need them to know
- Context: just enough background (cut the rest)
- What's new / what we did
- What it means for them / next steps
- The ask or the decision needed
```

## 6. The toast / wedding / occasion speech

```
- Open warm — a greeting + who you are to the person
- ONE good story that captures who they are (specific > generic praise)
- What that story reveals about them / the couple
- A heartfelt wish or lesson
- Raise the glass — a short, clean toast line
Keep it SHORT (2–4 min). End before they want you to.
```

## 7. The impromptu / on-the-spot answer

When put on the spot, silently pick one and go:

```
PREP:  Point → Reason → Example → Point (restate)
P-P-F: Past → Present → Future
W-S-N: What? → So what? → Now what?
```
Any of these turns panic into a tidy 30–60 second answer. (See
[Module 6](../curriculum/06-audience-and-qa.md).)

## The rehearsal checklist (before any real talk)

- [ ] Core message fits in one sentence
- [ ] Opening 30s is locked and memorized
- [ ] Closing line is locked and memorized
- [ ] At least one story/example per key point
- [ ] Rehearsed **out loud, on my feet** ≥ 4 times
- [ ] Rehearsed **to time** (and it fits, with margin)
- [ ] Rehearsed once for a live human, got feedback via the [rubric](self-assessment-rubric.md)
- [ ] Slides (if any) pass the "6 words / one image" test — and I have a no-slides backup
- [ ] I have my keyword card (not a script)
- [ ] Pre-talk nerves routine ready (breathing + warm-up + reframe)
